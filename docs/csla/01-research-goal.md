# 研究目标（01）

## 双线目标

- **CSLA**：AI 如何从经验中改变自己（Shared State + Experience Trace + Selective Credit + Consolidation）。
- **JCC**：Human+AI 如何共同维护与改变联合认知状态 J_t。

## 可辩护的 novelty（v1.8）

不把 Memory/RAG/Multi-agent/Planning/Search/World model/CoT/ReAct/Global workspace/
Persistent state 当原创。真正可守的研究边界：

> Shared Cognitive State + Human Insight Elicitation + Consequence-based Credit
> + Longitudinal Joint Learning + Adaptive Cognitive Runtime（不约束 frontier LLM）。

## 目标表述（严格）

不声称 CSLA > GPT。只证明 **LLM + CSLA > LLM**，且必须在相同 foundation model、
相同任务、相近成本下，检验 Longitudinal Learning / Generalization / Recovery /
Human Insight / Joint Performance 真的提升。
