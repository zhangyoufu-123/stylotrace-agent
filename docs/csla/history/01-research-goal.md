# 研究目标（01）

## 双线目标

1. **CSLA**：AI 如何从经验中改变自己？
   - 科学问题：冻结基座 LLM 下，持久认知状态 + 创新挖掘 + 后果驱动信用 + 选择性巩固，
     是否能在长期人机协作上优于 LLM-only / LLM+RAG / CoT / ReAct / 静态个性化 / reflection+memory？
2. **JCC**：Human+AI 如何共同改变联合认知状态？
   - 科学问题：联合状态 J_t 的维护与 alpha 控制权校准，是否让"人机共同产出"优于各自单独产出？

## 可辩护的 novelty 边界

CSLA 不是"新的认知架构"（CoALA 已覆盖骨架），唯一可辩护贡献：

> 在冻结基座 LLM、具备持久情景/图式记忆与结构化世界模型的 CoALA 类 agent 中，
> 一个可学习的"模块×时间×经验"信用信号（Shapley/配对干预做监督），既门控各模块更新、
> 又加权巩固，能否在等算力下改善长程完成率、恢复率与组合迁移，并优于
> terminal-reward-only 与 novelty/error-only 巩固两个强基线。

其余机制（记忆/世界模型/算子库/元控制/快慢学习）标注为"借用组件"，只在消融中报告边际贡献。
