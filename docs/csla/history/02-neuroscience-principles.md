# 神经科学原则（02）

**约束：** 只提取计算原则，不做脑区一一映射，不主张意识，不把类比写成神经科学事实（ADR-011）。

借用的计算原则：

- 海马式快速绑定：新经验快速形成可检索事件（M^E 写入快，η_fast）。
- 前额叶式目标维持与抑制：目标状态 G_t 与抑制向量（avoidance）维持任务方向。
- 纹状体式价值学习：结果误差驱动价值/信用更新（δ_t → credit → update）。
- 慢皮层式统计抽象：多次经验巩固为图式（M^S 写入慢，η_slow，带证据链）。
- 重放：离线重算经验以促进迁移与防遗忘（replay ≠ retrieval）。

多时间尺度（η_M > η_W > η_K > η_Π）是实验参数，不是生物学常数。
