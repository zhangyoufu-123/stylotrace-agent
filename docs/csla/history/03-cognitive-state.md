# 认知状态（03）— C1 修订

## C1：内容状态与参数状态分离（已冻结）

```text
S_t := ( S^C_t , Θ_t )
S^C_t = (G, B, M^E, P, U, Self, R)      # 内容状态：F_Θ 更新（快）
Θ_t   = (W, Π, K, M^S 参数, C_ψ)        # 参数状态：U_Θ 更新（慢，经学习事件）
```

消除 v1.2 中"状态更新函数 F 同时更新自身参数"的自指。`F` 负责内容转移，
`U` 负责参数学习；两者都经事件账本可审计。

## 联合状态（JCC 侧，见 10-jcc.md 单一权威）

```text
J_t = (H_t, A_t, S_t, W_t, G_t, I_t, α_t, U_t)
```

- `H_t`：对用户当前目标/约束/偏好的工作表示（≠读取用户内心）。
- `A_t`：AI 认知状态；`S_t`：共享状态；`W_t`：任务/证据模型；
- `G_t`：联合目标；`I_t`：交互状态；`α_t`：AI 主动权；`U_t`：不确定性/校准状态。

## 版本化与持久化

- 每个持久状态变更必须产生 CognitiveEvent 并递增 `state_version`（I2）。
- 生产默认模式 B：冻结基座 LLM，学习只发生在小模块（记忆/图式/信用估计器/轻量适配器）。
