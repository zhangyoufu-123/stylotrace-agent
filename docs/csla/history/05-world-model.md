# 世界模型（05）— C4 修订

## C4：防塌缩 + 结构化优先

- `L_W = D(z_{t+1}, hat z_{t+1})` 若 `z=E_W(o)`，编码器可平凡常数化。
- **锁定：** MVP 世界模型用"结构化/符号状态预测器"（任务状态机上的转移 + 不确定性），
  latent 后置；若启用 latent，必须带 stop-gradient / 对比 / 重建约束。
- 预测目标是"决策相关状态"，不预测像素、不预测全文。

## 误差通道（C2：双通道，禁止量纲混加）

```text
δ^W = D(z_{t+1}, hat z_{t+1})        # world 通道
δ^R = r_t + γV(S_{t+1}) − V(S_t)     # reward 通道（标准 TD）
```

两通道分别路由到世界模型与策略；需要标量输入的门控（写门/巩固优先级）用归一化后的分量。
