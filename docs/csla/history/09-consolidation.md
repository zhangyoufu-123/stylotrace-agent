# 巩固（09）

## Replay ≠ Retrieval

Replay 是离线学习：重放轨迹 → 重算 latent/结构化转移 → 优化预测损失；也可用于策略改进、
图式发现、反事实模拟、防遗忘。不是检索相关记忆。

## 巩固优先级

```text
V(e) = α·|δ_e| + β·IG + γ·GoalRel + δ·Credit + ε·Novelty > τ
```

分量先归一化（C5 同则），语义面向"未来能力提升"，与检索评分面向"当前查询有用"区分。

## 证据链与再巩固

- 每个 M^S 图式保留指向支持性情景的证据链（ADR-006），防止无依据自我强化。
- Reconsolidation：图式被检索后遇新证据可更新，版本化 `memory_v1→v2→v3`，记录证据来源。
- 危险模式：错误巩固/自我强化错误图式 → 需要消融 EXP-01 与证据链审计。
