# C1–C8 修订记录（design notes）

> 依据理论审计（CSLA_THEORY_AUDIT）与用户 2026-08-28 正式批准冻结。
> 这些修订是编码前必须写死并测试的数学定义；实现与本文档冲突时以本文档为准。

## C1 — 状态/参数自指

`S_t := (S^C_t, Θ_t)`。内容状态 S^C 由 F 更新，参数状态 Θ 由 U（学习事件）更新。
对应文档：03。

## C2 — 复合误差量纲混加

δ^W 与 δ^R 分双通道，分别路由到世界模型与策略；门控用归一化分量。
对应文档：05。

## C3 — 信用 baseline 不唯一

`C(i,t,e|B) := L_future(do(i,t,e=B)) − L_future(real)`，显式带基线 B；
B0/B1/B2 三档；小系统 Shapley、生产学习估计器 + 配对干预。对应文档：08。

## C4 — 世界模型塌缩

MVP 用结构化/符号状态预测器；latent 必须带 stop-grad/对比/重建约束。
对应文档：05。

## C5 — 记忆评分不可比

六分量先秩/分位归一化再加权；写门/巩固同则。对应文档：04、09。

## C6 — 口述置信不可靠

U_t 用采样一致性/熵；"置信→行动"用校准路由，不用固定阈值。
对应文档：07。

## C7 — 信用聚合防 reward hacking

不用裸求和；min-form/Shapley 归一；反事实配对运行。
对应文档：08、13。

## C8 — 与 CoALA 的 delta 必须明示

novelty 收缩为"冻结 LLM 下模块×时间×经验因果信用 + 选择性巩固"，并在论文/报告中明示。
对应文档：01。

## 集成冲突（随实现更新）

- 导演（单 LLM 决策）与 operator pool 的边界：导演=决策编排，生成=多算子。
- 风格系统（偏好层）与认知分层：Style→Preference→Decision Pattern→Task Schema 分层存储。
