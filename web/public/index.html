模型与 API Key

本地启动、自带密钥：选择服务商 → 粘贴你自己的 Key → 选模型。Key 只写入这台浏览器的 localStorage，请求时以 Authorization: Bearer 直达 LLM，服务端不留存、不代付。

留空 Key 时回退到服务端环境变量里的凭据（仅当部署方已配置）。清除后只删本机浏览器缓存，不影响服务端。
